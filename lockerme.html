สรุปสั้นที่สุด: แอปนี้ ไม่เก็บ ไม่ส่ง และไม่แชร์ข้อมูลส่วนบุคคลของผู้ใช้ ไม่มีระบบเก็บสถิติการใช้งาน ไม่มีโฆษณา และไม่มีเครื่องมือติดตามใด ๆ ข้อมูลทั้งหมดถูกเข้ารหัสในเครื่องของผู้ใช้ และเก็บอยู่บนเซิร์ฟเวอร์ที่ผู้ใช้ติดตั้งเอง

แอปนี้ทำอะไร

LockerMe เป็นหน้าจอสำหรับเข้าถึงคลังข้อมูลส่วนตัวที่ ผู้ใช้ติดตั้งและดูแลเซิร์ฟเวอร์เอง ตัวแอปไม่มีเซิร์ฟเวอร์กลาง ไม่มีบัญชีที่ผู้พัฒนาดูแล และผู้พัฒนาไม่มีทางเข้าถึงข้อมูลของผู้ใช้

แอปติดต่อออกไปยัง ที่อยู่เดียวเท่านั้น คือเซิร์ฟเวอร์ของผู้ใช้เอง และปฏิเสธการเชื่อมต่อไปที่อื่นทั้งหมด

การเข้ารหัส

ข้อมูลทุกชิ้นถูกเข้ารหัสในเครื่องของผู้ใช้ก่อนถูกส่งออก ด้วยกุญแจที่ได้จากรหัสผ่านหลัก (master password) ของผู้ใช้เอง รหัสผ่านหลักไม่เคยถูกส่งออกจากเครื่อง และไม่มีสำเนาอยู่ที่ใดนอกจากในความทรงจำของผู้ใช้

เซิร์ฟเวอร์เก็บได้เพียงข้อมูลที่เข้ารหัสแล้ว ซึ่งอ่านไม่ออกหากไม่มีรหัสผ่านหลัก หากผู้ใช้ลืมรหัสผ่านหลักและกุญแจกู้คืนพร้อมกัน ข้อมูลจะไม่สามารถกู้คืนได้โดยผู้ใด รวมถึงผู้พัฒนา — นี่คือคุณสมบัติที่ตั้งใจออกแบบไว้ ไม่ใช่ข้อผิดพลาด

ข้อมูลที่แอปเก็บไว้ในเครื่อง

แอปเก็บเพียงข้อมูลที่จำเป็นต่อการแสดงผลหน้าเว็บ ได้แก่คุกกี้เซสชันและการตั้งค่าธีม ทั้งหมดอยู่ในพื้นที่ของแอปเอง ไม่ถูกสำรองขึ้นคลาวด์ และไม่ถูกโอนไปเครื่องใหม่เมื่อผู้ใช้เปลี่ยนโทรศัพท์

สิทธิ์ที่แอปขอ

แอปขอสิทธิ์เพียงสองอย่าง คือ INTERNET และ ACCESS_NETWORK_STATE เพื่อติดต่อเซิร์ฟเวอร์ของผู้ใช้และตรวจสถานะการเชื่อมต่อ แอปไม่ขอสิทธิ์อ่านไฟล์ รายชื่อผู้ติดต่อ ตำแหน่ง กล้อง ไมโครโฟน หรือสิทธิ์อื่นใดทั้งสิ้น

มาตรการป้องกันบนอุปกรณ์

แอปเปิด FLAG_SECURE ไว้ตลอด ทำให้ระบบปฏิบัติการไม่อนุญาตให้ถ่ายภาพหน้าจอ และไม่แสดงเนื้อหาของแอปในหน้าสลับแอป เพื่อไม่ให้รหัสผ่านที่เปิดดูค้างอยู่ให้ผู้อื่นเห็น

บริการภายนอก

ไม่มี แอปนี้ไม่ใช้บริการวิเคราะห์ข้อมูล ไม่ใช้เครือข่ายโฆษณา ไม่ใช้บริการรายงานข้อขัดข้อง และไม่ส่งข้อมูลไปยังผู้พัฒนาหรือบุคคลที่สาม

เด็กและเยาวชน

แอปนี้เป็นเครื่องมือสำหรับผู้ที่ดูแลเซิร์ฟเวอร์ของตนเอง ไม่ได้ออกแบบมาเพื่อเด็ก และไม่มีการเก็บข้อมูลจากผู้ใช้ทุกช่วงอายุ

Privacy Policy

LockerMe · Last updated 10 September 2026

In short: this app collects, transmits and shares no personal data. No analytics, no advertising, no tracking of any kind. Everything is encrypted on the user's own device and stored on a server the user runs themselves.

What this app is

LockerMe is a window onto a personal vault that the user hosts themselves. There is no central service, no developer-operated account, and no way for the developer to reach a user's data. The app connects to exactly one address — the user's own server — and refuses to navigate anywhere else.

Encryption

Everything is encrypted on the device before it leaves, under a key derived from the user's own master password. The master password never leaves the device and exists nowhere but in the user's memory. The server holds ciphertext it cannot read. If the master password and the recovery key are both lost, nobody can recover the data — including the developer. That is a deliberate property of the design, not a limitation.

Data stored on the device

Only what the page needs to work: a session cookie and interface preferences, kept in the app's own storage. Neither is included in cloud backup nor transferred to a new phone.

Permissions

Two: INTERNET and ACCESS_NETWORK_STATE. The app requests no access to files, contacts, location, camera, microphone or anything else.

On-device protection

FLAG_SECURE is set for the lifetime of the app, so the operating system blocks screenshots and keeps the app's contents out of the recent-apps preview — a revealed password does not linger there for the next person to pick up the phone.

Third-party services

None. No analytics, no ad networks, no crash reporting, no data sent to the developer or anyone else.

Children

This app is a tool for people running their own server. It is not directed at children, and it collects no data from users of any age.
